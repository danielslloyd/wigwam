Connect to your Wigwam repository

Wigwam saves your list to GitHub. This page needs a key that can change only that one repository. The key stays in this browser, so set this up on your phone or computer, not the kids' device.

  1. Create a fine-grained token on GitHub ↗
  2. Under Repository access, choose Only select repositories and pick your Wigwam repo.
  3. Under Permissions → Repository permissions, set Contents to Read and write. Optionally, set Actions to Read-only so this page can show build progress.
  4. Generate the token, copy it, and paste it below.
